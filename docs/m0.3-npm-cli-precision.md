# M0.3 npm CLI precision evidence

## Evidence boundary

This is a bounded local scan and human triage of an explicitly authorized open-source checkout. It
is not a complete npm security audit, a clean bill of health, a vulnerability disclosure, or a
human-superiority result. The scanner did not execute target code, install target dependencies, use
its optional AI path, or access the network.

The frozen target was npm CLI 12.0.2 at
`b888cc9a9ff34a8b023ff47b784692396635397b`. Both comparison scans used Rust 1.92.0, the optimized
`secure-cli`, compact `secure-json-v1`, `--no-cache`, and explicit root and nested `node_modules`
exclusions. The baseline Engine source was
`16fd9c5a0545dd54efdfb18c9da35640ee7382b0`; the candidate is the commit containing this document.

`25e02a142d8a35fa5efa50e0e0d5437d58fd322370c7b2bbc4112ab10c43d93a` and

## Root-cause correction

Human triage of the retained SE1001 process-execution abstention established that its complete path
was inside a test harness expecting a fixed command. The original actor-authority calibration was
conservative, but it did not distinguish test-only runtime reachability and used an unrelated
framework-middleware limitation.

The correction reuses the general repository test-source classifier after semantic calibration. It
never excludes a test path or changes a proven security path. An already-abstained path whose every
retained step is test-only receives `test-context-reachability-unresolved`; test-only abstentions are
ordered after non-test abstentions; and SE1001/SE1004 receive rule-specific runtime limitations. No
target repository, path, symbol, command, package, or campaign identifier occurs in production
logic.

A neutral generated regression pairs:

- a production environment-controlled outbound request, which remains an
  `actor-authority-equivalence` abstention;
- a test-only environment-controlled process launch, which remains an abstention with explicit test
  context;
- a process launch with test endpoints and a production helper, which retains ordinary
  actor-authority calibration and non-test ordering;
- a test-source untrusted command reaching process execution, which remains a `security-path`
  finding and proves that tests are not blanket-excluded.

## Human triage status

- SE1004 at `lib/utils/oidc.js` remains an abstention: the request URL and bearer token are supplied
  by the same CI environment authority, and no distinct lower-privilege destination actor or
  reproducible disclosure was established.
- SE1013 at `workspaces/arborist/lib/arborist/rebuild.js` remains an abstention: the workspace
  lifecycle exception is documented as owner-managed, while supported attacker insertion,
  unintended policy crossing, and impact remain unresolved.
- SE1001 at `workspaces/libnpmpack/test/index.js` remains an abstention: production or CI
  reachability, distinct actor control, and impact remain unproven.

No item is promoted to a validated vulnerability. The three abstentions remain human-review leads,
and zero findings does not establish npm CLI security.

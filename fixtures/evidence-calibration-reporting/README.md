# Evidence-calibration and reporting fixture matrix

The core neutral corpus and expected semantic classes were fixed before any post-milestone holdout scan.
The initial valid nested-spread control already had the exact spread/member-call expression. After
the holdout showed that the grammar ambiguity depended on the preceding declaration boundary, that
structural variation and its malformed twin were added without importing target names, prose,
paths, or surrounding business logic. The expected valid/malformed classifications did not change.
The corpus contains no package-manager campaign, external-project path, historical commit, target
filename, setting name, or candidate fingerprint.

The matrix covers:

- a valid nested array spread followed by a member call and nearby malformed syntax;
- process-environment authority versus a lower-privilege request boundary;
- lexical path containment, canonical targets, opened handles, identity revalidation, and missing
  revalidation;
- reads, writes, removal, permission change, rename, archive extraction, and patch/update workflows;
- regular files, symbolic links, hard links, nested linked directories, replacement races,
  FIFOs/devices, Windows junction/reparse points, and mount boundaries;
- paths with an observable disclosure, modification, or availability channel and paths whose impact
  remains unresolved;
- wrappers, aliases, callbacks, metamorphic names, safe/unsafe flips, and explicit abstentions.

No fixture result is a vulnerability verdict. Runtime filesystem and actor-impact claims require
independent human validation.
